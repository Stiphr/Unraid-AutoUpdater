###2026.10.29
- Now called "Unraid Auto Updater", release build v1.0.0 (shown in the page, in Discord messages and in the README).
- Unraid OS: automatic install and optional automatic reboot. DEFAULT IS UNCHANGED: check and notify only. Install modes need your explicit confirmation, a maintenance window and a waiting period; stable releases only unless you allow more; a reboot is postponed during a parity check or rebuild; one automatic attempt per version; verified after the reboot.
- Manual "Install update" / "Install and reboot" / "Reboot now" buttons on the Unraid OS tab (with a confirmation).
- Discord messages now use the name "Unraid Auto Updater" and an orange-on-grey icon as avatar and header; you can set your own image URL in Settings.

###2026.10.28e
- Fix: updates now replace the installed files (Unraid only overwrites files that carry a checksum).
###2026.10.28d

###2026.10.28c

###2026.10.28b
- Update manager: per-container policies (auto / notify only / ignore), update delay tracked per image digest, maintenance window, critical containers that need your approval.
- Update preview with confirmation before manual (bulk) updates.
- Post-update verification (image, running state, health) with clear results; a container without a health check is not treated as a failure.
- Bounded retries for temporary pull errors only; old image removed only after a verified update (no more broad prune).
- Optional pre-update backups (config / image / appdata) with retention.
- Unraid plugin updates: detection, policies, delay, validation, recovery copy. Automatic installation is OFF by default.
- Unraid OS update detection and notification only (never installs or reboots).
- Discord webhook notifications (test button, per-category and per-type toggles, summary, rate-limit aware).
- New dashboard: overview, Docker table, Plugins table, Unraid OS, Settings, Activity.
- One dispatcher replaces one cron line per schedule; history, statistics, rotated log, export/import of settings.
- Settings from earlier versions are migrated automatically (a backup config.v1.backup.json is kept).
