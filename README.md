# Unraid AutoUpdater – Beta

> ⚠️ **For test servers only. Not for regular use.**
> The beta branch holds unfinished features and may break your setup. Do not install it on a server you depend on. Back up your flash drive first.

## Install the beta

In Unraid open **Plugins → Install Plugin** and paste:

```
https://raw.githubusercontent.com/Stiphr/Unraid-AutoUpdater/refs/heads/beta/unraid-autoupdater.plg
```

## Go back to stable

Install the stable plugin the same way:

```
https://raw.githubusercontent.com/Stiphr/Unraid-AutoUpdater/refs/heads/main/unraid-autoupdater.plg
```

Stable version, features and full instructions: see the [`main` branch](https://github.com/Stiphr/Unraid-AutoUpdater/tree/main). What is in the beta: [CHANGES.txt](CHANGES.txt).
